# Δασικές Πυρκαγιές Ελλάδα 2026 — Αρχείο Συνδέσμων (Links)

Φάκελος συλλογής και καθημερινής ενημέρωσης συνδέσμων από το διαδίκτυο (ελληνικά και αγγλόφωνα ειδησεογραφικά sites, blogs, επίσημες πηγές και πρακτορεία) που αφορούν **περιστατικά και θέματα δασικών πυρκαγιών στην Ελλάδα**.

## Αναπαραγωγή του αρχείου προόδου

Το xlsx **δεν συντηρείται με το χέρι**: ξαναχτίζεται από το LINKS ώστε να παραμένει συνεπές ακόμη και όταν προστίθενται αναδρομικά σύνδεσμοι παλαιότερων ημερομηνιών.

```bash
pip install openpyxl
python3 scripts/build_progress_xlsx.py        # ή: ... build_progress_xlsx.py 2026-08-14
```

## Κάλυψη

- **Περίοδος:** 1 Μαΐου 2026 → σήμερα (ενημερώνεται καθημερινά)
- **Γλώσσες πηγών:** Ελληνικά + Αγγλικά (διεθνή πρακτορεία)
- **Τύποι πηγών:** Ειδησεογραφικά sites, blogs, επίσημες πηγές (Πυροσβεστικό Σώμα, Πολιτική Προστασία, meteo.gr / Εθνικό Αστεροσκοπείο Αθηνών, EFFIS/Copernicus), διεθνή πρακτορεία (Reuters, AP, Guardian, BBC, Euronews κ.ά.)

## Σκοπός

Η συλλογή τροφοδοτεί μια **βάση γνώσης για τις πυρκαγιές του 2026**, που θα δημιουργηθεί στο τέλος της αντιπυρικής περιόδου (τέλη Οκτωβρίου 2026) αξιοποιώντας το περιεχόμενο των συνδέσμων.

## Μεθοδολογία

Η συλλογή γίνεται με εντατική αναζήτηση στο διαδίκτυο, ανά μήνα και ανά περιοχή, με συνδυασμό ελληνικών και αγγλικών ερωτημάτων. Κάθε εγγραφή περιλαμβάνει: ημερομηνία, περιοχή, πηγή, τίτλο άρθρου, URL και σύντομη περιγραφή.

**Πολυπηγαϊκή κάλυψη:** Επιδιώκουμε πολλαπλούς συνδέσμους για το ίδιο περιστατικό (διαφορετικά μέσα = διαφορετικά στοιχεία). Δεν φιλτράρουμε «διπλότυπα» ανά περιστατικό· αποφεύγεται μόνο η καταχώριση ακριβώς του ίδιου URL δύο φορές.

## Καθημερινή ενημέρωση

Το αρχείο ενημερώνεται καθημερινά με νέους συνδέσμους για τα περιστατικά της προηγούμενης/τρέχουσας ημέρας. Κάθε ενημέρωση καταγράφεται στο ημερολόγιο ενημερώσεων στο τέλος του κύριου αρχείου.

## Πίνακας ελέγχου (Dashboard) του βιβλίου «ΠΥΡΚΑΓΙΕΣ 2026»

Το ξεχωριστό βιβλίο `ΠΥΡΚΑΓΙΕΣ 2026.xlsx` (φύλλα «Ελλάδα», «Ευρώπη», «Στατιστικά», «Dashboard») ενημερώνεται από τον καθημερινό αυτοματισμό στατιστικών. Όταν ο αυτοματισμός ξαναγράφει το αρχείο με βιβλιοθήκη που δεν διαχειρίζεται γραφήματα, **το φύλλο «Dashboard» με τα 7 διαγράμματα χάνεται σιωπηλά**.

Αποκατάσταση:

```bash
python3 scripts/rebuild_dashboard.py "ΠΥΡΚΑΓΙΕΣ 2026.xlsx"
```

Η ένθεση γίνεται σε επίπεδο ZIP/XML, χωρίς να ανοίγει το βιβλίο με openpyxl, ώστε να μένουν ακέραια οι τύποι, οι πίνακες, η μορφοποίηση υπό όρους και τα checkboxes του φύλλου «Στατιστικά». Το script είναι idempotent: αν το «Dashboard» υπάρχει ήδη, το αντικαθιστά.

Τα εύρη των τύπων διευρύνονται σε `$2:$2000` (Ελλάδα) και `$2:$1000` (Ευρώπη) — το αρχικό πρότυπο ήταν καρφωμένο στις 500/300 γραμμές και υποεκτιμούσε τα σύνολα μόλις τα δεδομένα ξεπέρασαν το όριο.
